Transform before sharing.

Validate sensitive spans and the redacted text. Only the transformed handoff can reach the instruction check.

02 / GUARD

Keep permissions fixed.

Read ticket content as untrusted data against the approved support scope. Its risk and evidence change the export decision.

03 / INSPECT

Review the script separately.

Assess a proposed script as text. A benign ticket cannot overrule a risky command. The script is never executed.
